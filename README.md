CINEMO

당신의 다음 장면을 만나는 곳, CINEMO

CINEMO는 OTT 플랫폼을 참고하여 제작한 가상의 콘텐츠 서비스 웹사이트입니다.

HTML과 CSS를 활용하여 웹 페이지의 구조와 디자인을 구현하고, 다양한 화면 크기에서도 편리하게 이용할 수 있도록 반응형 웹을 적용한 프로젝트입니다.

※ 본 프로젝트는 학습을 위한 가상의 OTT 서비스이며, 콘텐츠와 인물은 모두 허구입니다. 실제 결제 및 영상 재생 기능은 제공하지 않습니다.

---

[ 프로젝트 소개 ]

프로젝트명: CINEMO

프로젝트 유형: OTT 플랫폼 웹사이트 클론 프로젝트

개발 기간: 2026.10.23 ~ 2026.10.30

개발 환경: Visual Studio Code

사용 기술: HTML, CSS

협업 도구: Git, GitHub

OTT 서비스의 UI를 참고하여 제작한 웹사이트입니다.
HTML과 CSS를 활용해 메인 페이지, 마이페이지, 프로필 선택 페이지를 구현하고
다양한 화면 크기에 대응하는 반응형 웹사이트를 제작하였습니다.

<br>

[ 프로젝트 목표 ]

OTT 서비스의 사용자 인터페이스를 분석하고 웹 페이지로 구현

HTML을 활용한 웹 문서 구조 작성 및 CSS를 활용한 디자인 구현 능력 향상

미디어 쿼리를 활용한 반응형 웹 디자인 경험

Git과 GitHub를 활용한 협업 및 버전 관리 경험 습득

팀원 간 역할 분담과 코드 통합을 통한 프로젝트 완성

<br>

[ 주요 기능 ]

메인 페이지: OTT 서비스 메인 화면 및 콘텐츠 카드와 목록 구성

내비게이션: 홈, 영화, 시리즈, 내가 찜한 콘텐츠 메뉴 구성 및 페이지 이동

마이페이지: 프로필 영역, 찜한 콘텐츠 목록 및 계정 설정 구현

프로필 선택 페이지: 프로필 이미지와 선택 화면 구성

공통 영역: 헤더와 푸터 구성 및 서비스 안내 정보 제공

반응형 웹: 미디어 쿼리를 활용하여 PC, 태블릿, 모바일 화면에 맞게 레이아웃 조정

마우스 반응: Hover 효과를 활용한 메뉴 및 링크 상호작용 구현
